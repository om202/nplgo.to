## नेपालमा QR Code: जिज्ञासाबाट अत्यावश्यक पूर्वाधारमा

यो केवल payment को कथा होइन। QR code ले नेपाली व्यवसायहरूले भौतिक र डिजिटल संसार कसरी जोड्छन् भन्ने कुरा मौलिक रूपमा परिवर्तन गरेको छ: restaurant menu, product packaging, event check-in, पर्यटक जानकारी, real estate listing, र marketing अभियान सबैमा QR code आवश्यक छ।

## Marketing QR Code vs Payment QR Code

यो भिन्नता महत्त्वपूर्ण छ र प्रायः गलत बुझिन्छ।

**Payment QR code** eSewa, Khalti, Fonepay, वा तपाईंको बैंकले बनाउँछ। यो तपाईंको merchant account मा link हुन्छ र scan गर्दा वित्तीय transaction trigger गर्छ।

## Technical गाइड: Print QR Code जसले साँच्चि काम गर्छ

यो खण्डले तपाईंको print गरिएको QR code scannable छ वा छैन भनी निर्धारण गर्ने specification हरू समेट्छ।

### Minimum Size

- **नजिकबाट scan** (business card, flyer, product label): minimum 2x2 cm। Business card मा 3 cm प्रयोग गर्नुहोस्।
- **मध्यम दूरी** (table tent, counter display): 4-6 cm राम्रो काम गर्छ।
- **दूरीबाट scan** (poster, banner, signage): 10:1 नियम प्रयोग गर्नुहोस्। QR code scanning distance को कम्तीमा 1/10 हुनुपर्छ।

### Resolution र DPI

- **300 DPI** सबै close-range print को लागि: business card, flyer, brochure, packaging, table tent।
- **150 DPI** large-format print को लागि स्वीकार्य: banner, billboard, trade show backdrop।
- npgo.to ले 2000x2000 pixel मा QR code generate गर्छ, जुन 300 DPI मा लगभग 17 cm (6.7 inch) सम्मको print को लागि पर्याप्त छ।

### File Format

- **SVG वा EPS**: vector format, quality loss बिना कुनै पनि size मा scale गर्न सकिन्छ।
- **PNG**: raster format, resolution पर्याप्त भए अधिकांश application को लागि राम्रो। npgo.to ले high-resolution PNG दिन्छ।
- **JPEG कहिल्यै नप्रयोग गर्नुहोस्।** JPEG compression ले module बीचको sharp edge blur गरेर scannability घटाउँछ।

### Contrast र Color

- QR code module (गाढा वर्ग) र background बीच minimum **4:1 contrast ratio** कायम गर्नुहोस्।
- **हल्का background मा गाढा module** standard हो।
- Inverted color (गाढा background मा हल्का code) बाट बच्नुहोस्, पुरानो device मा 40% सम्म scan reliability घट्न सक्छ।

### Quiet Zone

प्रत्येक QR code को वरिपरि "quiet zone" भनिने खाली border चाहिन्छ, कम्तीमा 4 module चौडा। यो बिना, scanner ले code को सीमा भरपर्दो रूपमा पहिचान गर्न सक्दैन।

QR code लाई tight crop नगर्नुहोस्। Text, logo, वा decorative element quiet zone मा overlap नगर्नुहोस्।
